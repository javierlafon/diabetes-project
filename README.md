## 🚀 Desafíos y Metodología
Este proyecto representó un **salto de escala** en mi formación. Dediqué un tiempo considerable a la etapa de exploración y limpieza rigurosa de datos para asegurar resultados significativos. 🧹📊

### Resumen del Proceso ETL:
* **Limpieza:** Conversión de valores nulos (`?`) y estandarización de categorías. Eliminación de columnas con >90% de nulos.
* **Ingeniería de Características:** Estandarización de tratamientos (23 columnas simplificadas a 1), creación de variables numéricas de edad y categorización de estancias hospitalarias.
* **Enriquecimiento:** Cruce estratégico con `ids_mapping` para traducir códigos clínicos a descripciones legibles.
* **Optimización Final:** Pasamos de un dataset original de **50 columnas** a un set refinado de **26 columnas**, listo para un análisis EDA profundo. 🚀
